# Changelog

## 2.5.0 — Foundry VTT 13

- Added a unified portrait options panel for borders, names, colored markers, and resource bars.
- Added optional custom names and per-character name styling and placement.
- Added per-character border styling and controls to apply border, name, or bar settings to all visible characters.

## 2.4.0 — Foundry VTT 13

- Added configurable bar height, bottom offset, spacing, and depleted-area opacity.
- Replaced the single new-bar controls with an **Add another bar** button.

## 3.2.0 — Foundry VTT 14

- Added configurable bar height, bottom offset, spacing, and depleted-area opacity.
- Replaced the single new-bar controls with an **Add another bar** button.

## 2.3.0 — Foundry VTT 13

- Added GM-managed colored markers to character portraits.
- Added multiple resource bars linked to numeric fields from character sheets.
- Added controls to create, edit, and remove markers and resource bars.

## 3.1.0 — Foundry VTT 14

- Added GM-managed colored markers to character portraits.
- Added multiple resource bars linked to numeric fields from character sheets.
- Added controls to create, edit, and remove markers and resource bars.

## 3.0.0 — Foundry VTT 14

- Added a dedicated package compatible with Foundry VTT 14.
- Carried forward all functionality from the Foundry VTT 13 release.

## 1.3.0 — Foundry VTT 11

- Added a numeric order field for each visible character.
- Characters with lower order values appear first.
- Characters with the same value retain their existing relative order.

## 2.2.0 — Foundry VTT 13

- Added a numeric order field for each visible character.
- Characters with lower order values appear first.
- Characters with the same value retain their existing relative order.

## 2.1.4 — Foundry VTT 13

- Constrained the configuration window to the available viewport height.
- Restored scrolling for the complete configuration form.
- Kept the Save button visible at the bottom of the window.

## 2.1.3 — Foundry VTT 13

- Increased the default height of the configuration window.
- Added a live character search field.
- Kept currently visible characters at the top of the list, in their configured order.

## 2.1.2 — Foundry VTT 13

- Aligned the general configuration fields into consistent two-column rows.
- Expanded the visible-character list to use the remaining window height.
- Fixed vertical scrolling in the visible-character list.

## 2.1.1 — Foundry VTT 13

- Fixed the ApplicationV2 configuration window by rendering its template with a single root HTML element.

## 2.1.0 — Foundry VTT 13

- Added a border color picker with immediate preview.
- Applied the saved color to every player's HUD.
- Kept `#dccdaf` as the default color.

## 2.0.0 — Foundry VTT 13

- Migrated the configuration window to ApplicationV2 and removed the jQuery dependency.
- Preserved position, orientation, size, names, offsets, and individual portrait framing.

## 1.2.0 — Foundry VTT 11

- Added a color picker for portrait borders.

## 1.1.0 — Foundry VTT 11

- Added configurable horizontal and vertical offsets from 0 to 1000 pixels.
